# 📱 PDM2526 Project – IPCA Android Studio

Este repositório reúne os projetos desenvolvidos nas aulas da unidade curricular **Programação para Dispositivos Móveis (PDM)**, do curso de **Engenharia de Sistemas Informáticos** do **IPCA**.

Cada projeto tem uma **componente de avaliação**, focando diferentes tópicos e competências do desenvolvimento Android com **Kotlin** e **Jetpack Compose**.

---

## 🧩 Projetos Desenvolvidos

### 🧮 Projeto 1 — Calculadora e Conversor
**Avaliação:** _Composable UI_  
**Descrição:**  
Desenvolvimento de uma aplicação com duas funcionalidades principais:
- **Calculadora:** operações matemáticas básicas (soma, subtração, multiplicação e divisão).  
- **Conversor:** conversão entre diferentes unidades (ex.: temperatura, moeda, distância, etc.).  

**Objetivo:** Avaliar a utilização dos **componentes de interface (Composable)**, **layout responsivo** e **interação com o utilizador** no Jetpack Compose.

---

### 🧠 Projeto 2 — Functional Programming e WebAPI
**Avaliação:** _Lists_  
**Descrição:**  
Criação de uma aplicação que consome dados de uma API Web (via **OKHTTP**) e apresenta resultados através de **listas dinâmicas (LazyColumn)**.

**Objetivo:** Avaliar o uso de **programação funcional em Kotlin**, **manipulação de listas**, **funções de ordem superior** e **integração com Web APIs**.

---

### 🧭 Projeto 3 — Navigation
**Avaliação:** _Navegação entre ecrãs_  
**Descrição:**  
Implementação de uma aplicação com **múltiplos ecrãs** e **navegação estruturada** através do **Jetpack Navigation Component**.

**Objetivo:** Avaliar a capacidade de **gerir rotas**, **passar dados entre ecrãs** e **organizar fluxos de navegação** em aplicações Android modernas.

---

### 🌐 Projeto 4 — Web API com OKHTTP
**Avaliação:** _Integração com APIs_  
**Descrição:**  
Desenvolvimento de uma aplicação que realiza **requisições HTTP** a uma **API pública** utilizando a biblioteca **OKHTTP**, processando e apresentando os dados obtidos.

**Objetivo:** Avaliar a capacidade de **consumir dados remotos**, **gerir respostas JSON**, e **atualizar a interface** com base nos resultados obtidos.
